Formatted messages require escaping event values for the selected format.
Only the message text is templated. The Telegram JSON is escaped automatically. Telegram accepts up to 4096 characters after formatting.
Connection

HTTPS verifies the server certificate and hostname. Stored credentials are hidden from read APIs and saved in a private configuration file.

Template help

Templates use MantidsLang with the input event JSON as the root context. JSON output: {{#print_json[$]!}}. Text field: {{#print_raw[$INFO.host]!}}. HTML-escaped field: {{#print_htmlescaped[$INFO.host]!}}. Conditions and foreach loops are supported. File includes are disabled. Use print_json for values embedded in a JSON body.

Changes apply to the running configuration. Use Save to disk on the actions page to keep them after a restart.
