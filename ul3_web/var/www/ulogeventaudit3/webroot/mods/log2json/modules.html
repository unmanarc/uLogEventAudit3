Each module filters the process / logger name, matches the message and fills a JSON template from its captures. Every matching module emits one event. Unmatched messages are ignored; auditd uses its built-in parser.

Filters search for a match; use ^ and $ to match the entire value. The PID is excluded from the logger name.

Template syntax

Use whole template values such as (string)<$1> for text or (integer)<$2> for a number. Quotes around typed placeholders are optional. Bare "$1" is literal text. Supported types: string, integer, unsigned, number, boolean and null. Captures come from the message regex; $0 is the entire match. Missing or invalid captures use type defaults.
