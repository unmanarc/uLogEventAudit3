# uLogEventAudit3 - Unmanarc's Log and Event Audit Platform

uLogEventAudit3 is a high-performance tool designed to efficiently process auditd logs received through rsyslog. Widely deployed in enterprise environments, it excels at identifying potential security threats and delivering real-time alerts via messaging platforms, bots, or other notification systems.

Additionally, uLogEventAudit3 can aggregate and decode auditd messages into JSON structures, making it easy to forward the data to other systems such as ELK stacks for further analysis and visualization.

## Applications

### [ul3_log2json](ul3_log2json/README.md)
This module is responsible for converting raw auditd log entries into structured JSON format. This facilitates easier integration with data analysis tools and platforms that consume JSON input, such as ELK stacks.

### [ul3_alert](ul3_alert/README.md)
Designed to monitor processed audit logs for suspicious activities or security threats in real-time. It triggers alerts through configured messaging systems when potential issues are detected, ensuring timely responses to potential breaches.

### [ul3_web](ul3_web/README.md)
Provides a web-based interface to view and manage audit logs and alerts generated by uLogEventAudit3. This module allows administrators to access log data and security alerts via a user-friendly web portal for better visibility into system activity.

## Build Requirements 

This should be built on top of:

- libMantids30 3.0 - https://github.com/unmanarc/libMantids30
- uFastAuthD3 for web authentication
- Boost 1.75+ (JSON, regex, thread)
- C++17

## Minimum System Requirements

- CPU: 1 to N processors (optimized to be multithreaded)
- MEM: Min: 256M (depending on your configuration you may want more)
- Storage: Min: 16Gb including the whole container/OS), you may want to add more storage to keep some logs for long periods of time.

So... would it run in my Raspberry PI 4? 

YES. But in our experience, RPI4 only delivers enough power to analyze some thousands of simultaneous servers with an average usage.
